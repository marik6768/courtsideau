# COURTSIDE

NBA analytics · GOAT Index · forecasts · editorial.

All files are in the **root** (no subfolders). Ready for GitHub Pages.

## Upload to GitHub

1. Create a new repository on GitHub.
2. Click **Add file → Upload files**.
3. Select **all files** from this folder (Ctrl+A / Cmd+A) and drag them in.
4. Commit.
5. **Settings → Pages** → Source: Deploy from branch `main`, folder `/ (root)`.

Site: `https://YOUR_USER.github.io/REPO_NAME/`

## Local

Open `index.html` in a browser, or:

```bash
npx serve .
```

Admin: `editor.html` (any email + password).
